# Database Schema\n\n## Overview\n\nThe Donor Assistance App uses PostgreSQL as its primary database.\n\n## Key Tables\n\n### Users\n- `id` (UUID) - Primary key\n- `email` (VARCHAR) - Unique email\n- `password` (VARCHAR) - Hashed password\n- `first_name`, `last_name` (VARCHAR)\n- `role` (VARCHAR) - donor, beneficiary, admin\n- `status` (VARCHAR) - active, inactive, suspended\n- `created_at`, `updated_at` (TIMESTAMP)\n\n### Beneficiaries\n- `id` (UUID) - Primary key\n- `user_id` (UUID) - Foreign key to users\n- `category` (VARCHAR) - orphan, poor, physically_challenged\n- `status` (VARCHAR) - pending, verified, rejected\n- `total_received` (DECIMAL) - Total donations received\n- `created_at`, `updated_at` (TIMESTAMP)\n\n### Donations\n- `id` (UUID) - Primary key\n- `donor_id` (UUID) - Foreign key to users\n- `beneficiary_id` (UUID) - Foreign key to beneficiaries\n- `amount` (DECIMAL) - Donation amount\n- `status` (VARCHAR) - pending, completed, failed, refunded\n- `payment_method` (VARCHAR) - stripe, paypal, bank_transfer\n- `created_at`, `updated_at` (TIMESTAMP)\n\n## Migrations\n\nAll database changes are managed through migration files in `backend/migrations/`.\n\nTo run migrations:\n```bash\ncd backend\nnpm run migrate\n```\n
