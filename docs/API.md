# API Documentation\n\n## Overview\n\nThis document describes all available API endpoints for the Donor Assistance App.\n\n**Base URL:** `http://localhost:5000/api`\n\n## Authentication\n\nAll protected endpoints require a JWT token in the `Authorization` header:\n\n```\nAuthorization: Bearer <token>\n```\n\n## Endpoints\n\n### Authentication\n\n#### Register User\n- **POST** `/auth/register`\n- **Body:**\n  ```json\n  {\n    \"email\": \"user@example.com\",\n    \"password\": \"securepassword\",\n    \"firstName\": \"John\",\n    \"lastName\": \"Doe\",\n    \"role\": \"donor\"\n  }\n  ```\n\n#### Login\n- **POST** `/auth/login`\n- **Body:**\n  ```json\n  {\n    \"email\": \"user@example.com\",\n    \"password\": \"securepassword\"\n  }\n  ```\n\n### Users\n\n#### Get User Profile\n- **GET** `/users/profile`\n- **Headers:** `Authorization: Bearer <token>`\n\n#### Update User Profile\n- **PUT** `/users/profile`\n- **Headers:** `Authorization: Bearer <token>`\n\n### Beneficiaries\n\n#### List All Beneficiaries\n- **GET** `/beneficiaries`\n\n#### Get Beneficiary Details\n- **GET** `/beneficiaries/:id`\n\n#### Create Beneficiary Profile\n- **POST** `/beneficiaries`\n- **Headers:** `Authorization: Bearer <token>`\n\n### Donations\n\n#### Create Donation\n- **POST** `/donations`\n- **Headers:** `Authorization: Bearer <token>`\n\n#### Get Donation History\n- **GET** `/donations/history`\n- **Headers:** `Authorization: Bearer <token>`\n\n### Admin\n\n#### Verify Beneficiary\n- **POST** `/admin/beneficiaries/:id/verify`\n- **Headers:** `Authorization: Bearer <admin-token>`\n\n#### Get Dashboard Stats\n- **GET** `/admin/stats`\n- **Headers:** `Authorization: Bearer <admin-token>`\n\n## Error Responses\n\nAll errors follow this format:\n\n```json\n{\n  \"success\": false,\n  \"message\": \"Error description\",\n  \"error\": \"ERROR_CODE\"\n}\n```\n
