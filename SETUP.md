# Setup Guide - Donor Assistance App\n\n## Prerequisites\n\n- Node.js (v18+)\n- npm or yarn\n- PostgreSQL (v12+)\n- Git\n- Docker (optional, for containerization)\n\n## Quick Start\n\n### 1. Clone and Install\n```bash\ngit clone https://github.com/sonaws14331/donor-assistance-app.git\ncd donor-assistance-app\nnpm install\n```\n\n### 2. Setup Environment\n```bash\ncp .env.example .env\ncd backend && cp .env.example .env\ncd ../frontend && cp .env.example .env\ncd ..\n```\n\n### 3. Database Setup\n```bash\n# Create PostgreSQL database\npsql -U postgres -c \"CREATE DATABASE donor_assistance_app;\"\n\n# Run migrations\ncd backend\nnpm run migrate\n```\n\n### 4. Run Application\n```bash\n# From root directory\nnpm run dev\n```\n\nThe app will be available at:\n- Frontend: http://localhost:3000\n- Backend: http://localhost:5000\n\n## Using Docker\n\n```bash\ndocker-compose up --build\n```\n\n## Project Structure\n\n```\ndonor-assistance-app/\n├── backend/                 # Node.js/Express API\n│   ├── src/\n│   │   └── server.js       # Entry point\n│   ├── package.json\n│   ├── Dockerfile\n│   └── .env.example\n├── frontend/                # React application\n│   ├── src/\n│   │   ├── App.jsx\n│   │   ├── pages/          # Page components\n│   │   └── ...\n│   ├── package.json\n│   ├── vite.config.js\n│   └── .env.example\n├── docs/                    # Documentation\n│   ├── API.md              # API endpoints\n│   └── DATABASE.md         # Database schema\n├── docker-compose.yml\n├── package.json\n└── .env.example\n```\n\n## Development Workflow\n\n### Start All Services\n```bash\nnpm run dev\n```\n\n### Backend Only\n```bash\ncd backend && npm run dev\n```\n\n### Frontend Only\n```bash\ncd frontend && npm run dev\n```\n\n## Next Steps\n\n1. **Database Setup** - Create migration files for initial schema\n2. **Authentication** - Implement JWT-based auth routes\n3. **User Management** - Build registration and profile endpoints\n4. **Beneficiary Module** - Create beneficiary verification workflow\n5. **Donation Flow** - Implement payment processing\n6. **Admin Panel** - Build admin dashboard\n\n## Documentation\n\n- See `docs/API.md` for API endpoints\n- See `docs/DATABASE.md` for database schema\n- See `CONTRIBUTING.md` for contribution guidelines\n
